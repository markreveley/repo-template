# Next steps for the operator

Read with [`next-agents.md`](next-agents.md).

## 1. Say when to commit

The repo is built and uncommitted. Say "commit" in a session here, or run:

```sh
cd ~/dev/repos/repo-template && git add -A && git commit -m "The layout template: README, governance stubs, md/ folders with READMEs, the layout check" && git push -u origin main
```

## 2. Turn on the template setting, if you want new repos made from this one

GitHub: repo Settings, General, tick "Template repository". New repos then get "Use this template".
